What MIRA cannot represent from this diagram

entails The H→P arrows are invisible in MIRA. All three hypotheses and their four predictions collapse into a flat set of mira:Claim nodes with no derivation relation between them. A reader cannot tell which prediction belongs to which hypothesis. no MIRA predicate
tests The P→E dashed arrows are invisible. MIRA represents confirmed evidence as mira:supports, but cannot distinguish "this empirical result was designed to test this specific prediction" from generic post-hoc support. no MIRA predicate
reproductions Three claims carry verified reproduction records (insula peak MNI, happiness β values, R² exact match). MIRA has no node type for verification — badges are invisible. no MIRA node type
