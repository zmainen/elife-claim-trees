# What this corpus's own scripts need beyond the standard library.
#
# The machinery's dependencies are declared in the machinery, at
# ../claim-graphs/requirements.txt, and are not copied here — a copy is a second list that must
# agree with the first and nothing checks that it does. Install both:
#
#   pip install -r requirements.txt -r ../claim-graphs/requirements.txt
#
# Both are needed, not just this one, because the scripts that remain here import machinery
# modules: corpus_facts reaches claim_graphs.verdicts, export_mira and relations; article_json
# reaches claim_graphs.sources. Those pull in pydantic, anthropic, httpx and oxa-types at
# module level, which is why they appear in the machinery's list and not in this one.
#
# The data generators were described as standard-library-only when CI was first wired, and it
# failed on all three Python jobs because they are not. It passed locally only because the
# packages happened to be installed. Pinned loosely — nothing here depends on a version.

# corpus_facts, article_json and extract-bibliography all read YAML.
PyYAML>=6.0

# article_json parses JATS with lxml.etree. (patch-figure-provenance uses the standard
# library's ElementTree and needs nothing.)
lxml>=4.9
